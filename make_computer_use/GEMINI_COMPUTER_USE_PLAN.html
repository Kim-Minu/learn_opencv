Gemini 기반 Computer Use 에이전트 기획 및 설계서

Google Gemini 2.5 / 2.0 Flash 멀티모달 모델과 Python / OpenCV 하이브리드 비전 기술을 결합하여, 사람처럼 컴퓨터 화면을 보고 마우스와 키보드를 직접 조작하는 자율형 GUI Agent 시스템 명세입니다.

1. 동작 기본 원리 2. 핵심 기능 요구사항 3. Function Calling 스키마 4. 기술 스택 5. 개발 로드맵

동작 기본 원리 (Sense-Think-Act Loop)

GUI 에이전트는 사람이 모니터를 바라보고 두뇌로 판단한 뒤 마우스와 키보드로 조작하는 과정과 동일한 폐루프(Feedback Loop) 제어 시스템을 따릅니다.

핵심 기능 요구사항 정의

👁️ 1. 화면 관측 및 시각 전처리 (Sense)
Screen Capture

초고속 화면 캡처

mss 라이브러리를 통해 100ms 이내에 풀스크린을 캡처하고 멀티 모니터를 지원합니다.

Coordinate Scale

Retina / HiDPI 해상도 정규화

화면 좌표를 0~1000의 상대 좌표계(Normalized Coordinate)로 일원화하여 디스플레이 배율 차이를 자동 보정합니다.

OpenCV Vision

좌표 그리드 오버레이 & 템플릿 매칭

캡처 이미지 위에 100단위 반투명 그리드선을 그려 모델의 클릭 오차를 줄이고, 주요 아이콘은 OpenCV 템플릿 매칭으로 픽셀 단위로 정밀 보정합니다.

🧠 2. 의사결정 및 추론 엔진 (Think)
Gemini Multimodal

Gemini 2.5 / 2.0 Flash 추론

초저지연 멀티모달 추론으로 현재 화면 상태를 분석하고 자연어 태스크를 하위 컴퓨터 액션들로 분해합니다.

Structured Output

Function Calling 강제

자유 텍스트 답변 대신 미리 정의된 JSON Tool Call 형태(클릭, 타이핑, 단축키 등)로만 액션을 방출하도록 스키마를 강제합니다.

Context Management

슬라이딩 윈도우 문맥 관리

최근 3~5스텝의 액션 로그와 화면 변화 결과를 유지하여 같은 위치를 헛클릭하는 무한 루프를 방지합니다.

⚡ 3. OS 제어 및 조작 실행기 (Act)
Mouse Control

마우스 정밀 조작

좌/우/더블 클릭, 드래그 앤 드롭, 상하 스크롤을 완벽 지원하며 부드러운 커서 이동을 제공합니다.

Keyboard & Korean

한글 클립보드 호환 타이핑

OS 타이핑 시 한글 자모 깨짐을 방지하기 위해 pyperclip을 활용한 복사-붙여넣기 우회 방식을 적용합니다.

Shortcuts

복합 단축키 실행

Cmd + Space, Ctrl + C / V, Alt + Tab 등 애플리케이션 전환 및 필수 단축키를 구동합니다.

🛡️ 4. 안전장치 및 인터럽트 제어 (Safety)
Fail-Safe

모서리 마우스 이동 즉시 정지

PyAutoGUI Fail-Safe를 활성화하여 사용자가 마우스를 화면 구석으로 강제 이동시키면 즉시 모든 작업이 중단됩니다.

Loop Guard

최대 스텝 수 제한 (Max Iterations)

예상치 못한 루프 발생 시 15~20스텝 도달 시 자동 일시정지 후 사용자의 인터벤션을 요구합니다.

Human-in-the-Loop

민감 영역 차단 및 승인 모드

결제창, 비밀번호 입력 필드, 시스템 설정 등의 위험 액션 감지 시 사용자 확인 모달을 띄웁니다.

권장 기술 스택 (Tech Stack)

영역 기술 / 라이브러리 선정 이유
AI 추론 엔진 google-genai (Gemini 2.5 / 2.0 Flash) 초저지연 멀티모달 비전 처리, 높은 한국어 이해도, 완벽한 Function Calling
화면 캡처 mss, Pillow OS 독립적 초경량 고속 캡처 (100ms 이내), 멀티 모니터 완벽 지원
비전 & 전처리 OpenCV (cv2), numpy 좌표 그리드 오버레이, 화면 차분 감지(SSIM/Diff), 템플릿 매칭 보정
OS 제어 pyautogui, pyperclip, pynput 크로스 플랫폼 마우스/키보드 에뮬레이션, 한글 클립보드 안전 타이핑
설정 & 유효성 python-dotenv, pydantic API Key 보안 관리 및 Structured Tool Output 검증

단계별 개발 로드맵 (Roadmap)

1

Step 1: 화면 캡처 및 좌표계 변환 모듈 (MVP 관측)

mss 기반 화면 캡처 모듈을 만들고, 0~1000 상대 좌표와 실제 디스플레이 물리 픽셀 간의 스케일 팩터 변환 수식을 구현 및 테스트합니다.

2

Step 2: OS 조작 액터 모듈 (MVP 제어)

pyautogui 기반 클릭, 타이핑, 클립보드 한글 붙여넣기, 단축키 실행 함수를 구현하고 Fail-Safe 비상 정지 로직을 장착합니다.

3

Step 3: Gemini 멀티모달 도구 루프 연동 (Agent 핵심)

현재 스크린샷과 사용자 목표를 Gemini에 전달하고, 반환된 Function Call을 실행한 뒤 다음 화면을 피드백하는 자율 실행 루프를 완성합니다.

4

Step 4: OpenCV 기반 비전 정밀 보조

화면 위에 100단위 반투명 그리드(Grid Overlay)를 합성하여 모델의 클릭 좌표 정밀도를 대폭 끌어올리고, 화면 차분 감지로 클릭 성공 여부를 판정합니다.

5

Step 5: 대시보드 및 가드레일 안정화

에이전트의 현재 사고 과정(Thought)과 클릭 위치를 화면에 시각화하고, 결제 및 시스템 설정 등 민감 창 진입 시 사용자 확인 절차를 구축합니다.

💡 다음 단계 제안:
바로 프로젝트 환경 구성(requirements.txt)과 Step 1 화면 캡처 & 좌표계 변환 모듈(screen.py) 코드를 작성하여 실제 동작을 검증해 볼 수 있습니다.
